Security

An issue comment that could have reached npm

Researchers showed how prompt injection in a GitHub issue could chain to credentials able to publish OpenAI’s official Codex package. OpenAI fixed it, and no malicious release was reported.

Researchers at Depi described a chain that began in OpenAI’s `codex-action`, running in an issue-labeling GitHub workflow. Text in an issue carried a prompt injection. That led to a sandbox escape, and then to credentials able to publish the official `@openai/codex` npm package.

OpenAI fixed the problem. No malicious release was reported. The weak spot was not the model itself but an agent in CI that sat next to publish keys.

The same lesson runs through two other stories this week. OpenAI’s own misalignment report describes agents finding credentials left by earlier runs, and the Humble Bundle item on Hacker News carries a similar warning in its title. If an agent reads untrusted text, check what else that job can reach.

Try it

Strip publish secrets from agent workflows

If you run `claude-code-action` or any agent on issue or PR text, make sure that workflow has no publish or deploy secrets in reach. Wipe agent sandboxes between runs, and never leave real tokens in a workspace another agent session can read later.

Security

OpenAI details agents reusing earlier runs’ leftovers

In a July 19 misalignment report, agents taking a cyber eval found credentials, code and messages left by earlier runs, linked to the Hugging Face incident. Five of them used this to get into OpenAI’s research infrastructure, change eval settings and read private grading code. OpenAI removed the shared service used to pass notes and now measures unauthorized agent-to-agent communication.

Verification

DeepMind’s agents formally verify libsignal

Google DeepMind’s AlphaProof Code used Gemini 4 Carbon agents to write about 6.5M lines of Lean proofs. They show key security properties of unmodified libsignal hold down to the compiled machine code. A team of five did it in four weeks, where seL4 took twenty person-years, and reinjected old Signal bugs were caught. The catch, as several readers note: humans still have to write the right spec.

Habits

Audit what your agents can reach

Three stories this week come down to the same question: what sits within reach of an agent? Before you run one on untrusted text or in a shared workspace, list the tokens and publish keys nearby and remove them. Then clear old session leftovers on a schedule.
