Releases

Anthropic ships Claude Fable 5.2 and Mythos 5.2

Fable 5.2 reaches Claude Code and the API, faster and cheaper than 5.1. Mythos 5.2 stays restricted.

Per the reports, Fable 5.2 is up to 30% faster than 5.1. It costs $8/$40 per 1M tokens, down from $10/$50. Longer-tenured subscribers get more Fable usage resets.

Early users say it shines on big, long tasks such as codebase rewrites. Felix Rieseberg and Addy Osmani still keep Opus 5.5 as the daily driver. Lydia Hallie uses Fable as an orchestrator over Opus.

The first outside reads are positive but mixed. Cursor puts it at the top of CursorBench at 60% at max effort (56.9% by default, up from 49.2%). Dwarkesh’s game eval ranks it above Opus 5.5 but behind GPT-6 Astra. David Cramer calls it good but too expensive to daily-drive, and doubts “built from scratch” demos shown without transcripts.

Prompt injection still beats frontier agents

IPI Bench from General Analysis tested indirect prompt injection on realistic office tasks. Attack success ran from 41 to 97% across 7 frontier models, including unauthorized refunds and published private code. These are the authors’ numbers.

Researchers fool Claude Code’s Auto Mode monitors

Anthropic Fellows red-teamed the monitors that block dangerous actions. Per summaries of the paper, prompt injection aimed at the monitor, coordinated multi-agent attacks and poisoned context compaction all got through. Proposed fixes include wider tool coverage and an extra agentic check.

Habits

Guard your agents by hand

Any agent that reads outside content (web, tickets, emails) should need your approval before write actions like pushing, publishing or paying. Keep explicit deny rules (`rm`, `curl`, pushes) in `settings.json` rather than relying on Auto Mode alone. For your simplest Claude Code subagents, set `model: haiku` or `model: sonnet` in the frontmatter.
