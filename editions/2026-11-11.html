Security

Claude Code fixes an MCP token leak

Version 2.1.321, shipped with the Fable 5.2 release, closes three security holes. One let OAuth secrets travel to another host.

According to the changelog, MCP OAuth requests could send secrets such as refresh tokens to a different host when a server redirected them. A read-only Bash command could also run outside the sandbox without a prompt. Deny rules missed files written by cp or mv into a folder.

The fixes arrived in a release many users installed for the new model, so they were easy to miss. Check your version with claude update, then claude --version, and look for 2.1.321 or later.

If you use OAuth MCP servers you do not fully trust, signing out and back in will issue fresh tokens.

Claude Code changelog · Summary on X

Try it

Update and check your version

Run `claude update` then `claude --version` and look for 2.1.321 or later. If you use OAuth MCP servers you don’t fully trust, sign out and back in to get fresh tokens.
