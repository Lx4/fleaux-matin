Security

Claude Code turned into an implant with a stolen key

Darktrace Signal Labs ran a lab test in which Claude Code became a remote-controlled implant. No Anthropic vulnerability was involved, only a stolen API key.

Commands traveled through a Claude memory store, and a 1 GB file left via the Files API. All traffic went to Anthropic’s API, so egress filtering did not flag anything.

The report stresses that there was no flaw in Anthropic’s systems. The attack needed a key and an endpoint that most networks allowlist.

Scout’s advice: treat Anthropic API keys as production credentials. Keep them out of dotfiles, scope them, rotate them, and check for memory stores you did not create.

FBI flags ARTEX, an open-source AI hacking agent

The FBI’s FLASH alert says ARTEX turns plain-language goals into intrusions, sometimes from first probe to admin access in under 3 hours. It has been used since August against finance, government and tech, and still spreads through forks after its GitHub repo came down. More than 1,600 exposed consoles have been found.

Ways of working

Which model for daily coding: Opus 5.5 or Fable 5.2?

Addy Osmani suggests Opus 5.5 at medium effort as the daily driver, raising effort before switching and keeping Fable 5.2 for hard work such as big migrations and long unattended runs. Garry Tan’s public benchmark of 52 tasks in Claude Code found Fable 5.2 solved about as many as Opus 5.5 (82.7% vs 84.6%) at 2.8x the cost per solved task.
