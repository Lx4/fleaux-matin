Outage

Claude and Claude Code hit by hours of errors

Elevated errors and login failures hit claude.ai, Claude Code and platform.claude.com from about 10:58 Paris time. Anthropic deployed a fix at 12:05, but many users still reported problems.

Anthropic’s status page showed elevated errors across the three services. The company said it was monitoring after the fix, while many users on X kept reporting Claude as down.

The incident came on the same day as the Microsoft 365 outage. Anthropic has not linked the two. The status incident drew 488 points on Hacker News.

If a Claude Code session dropped, check the status page before re-running long tasks, then re-authenticate once the incident shows as resolved.

Try it

Scan your agent skills before trusting them

Install NVIDIA’s SkillSpector with `uv tool install git+https://github.com/NVIDIA/skillspector.git`, then run `skillspector scan ~/.claude/skills/ --recursive --no-llm` on the skills you already have installed.

Security

Cursor’s breach began at a vendor

Cursor’s post-mortem on the fake Claude Code extension of Oct 29 traces it to a key issued to its inference vendor Fireworks, which exposed it. Old agent traces (non-Privacy Mode) held unredacted credentials, leading to internal SaaS tools and then the marketplace cache. Cursor has dropped Fireworks and rotated all its credentials.

Habit

Make your Stop hooks exit 2

Per Lydia Hallie, a Claude Code Stop hook only makes Claude retry when it exits with code 2. Exit 2 sends Claude back with the hook’s stderr, while exit 1 is non-blocking and Claude finishes anyway. Check your test and lint hooks.
