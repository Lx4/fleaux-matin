Developer tools

Claude Code tries a Code Mode that runs calls in parallel

An experimental setting lets Claude write a short JavaScript program instead of calling tools one by one. The docs flag a safety trade-off in auto mode.

Code Mode is available in Claude Code v2.1.323 and later, in the terminal only. Claude writes a bit of JavaScript that runs several tool calls in parallel and returns only what it needs. Daniel San reported 13 tool calls done in 2 model turns.

There is a catch, according to the docs. In auto mode, the classifier reviews the code as a whole, not each tool call. That makes your deny rules and hooks matter more.

To test it, start Claude Code with CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1, ask it to find broken links across your Markdown files, then press Ctrl+O to read the code it wrote.
